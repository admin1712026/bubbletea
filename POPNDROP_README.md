## 🚀 КАК ЗАПУСТИТЬ

### Шаг 1: Создать таблицы в Supabase (ЭТО ВАЖНО!)

```
1. Откройте https://app.supabase.com
2. Выберите проект (luukovzdyaxilhhuwxou)
3. Перейдите в SQL Editor
4. Создайте новый query
5. СКОПИРУЙТЕ ВСЕ содержимое файла supabase_setup.sql
6. Нажмите Run (Ctrl+Enter)
```

✅ Это создаст все таблицы с данными и примерами.

### Шаг 2: Проверить что сервер запущен

```bash
npm run dev
```

Сервер уже работает на **http://localhost:3000** ✅

### Шаг 3: Открыть в браузере

```
http://localhost:3000     - Главная страница
http://localhost:3000/menu - Полное меню
```
