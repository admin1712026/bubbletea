## 🔌 КАК ПОДКЛЮЧИТЬ ДИНАМИЧЕСКИЕ ДАННЫЕ

### Пример 1: Добавить напитки из Supabase в меню

В `public/script.js` уже есть функция `loadDrinksFromSupabase()`. Можно расширить её:

```javascript
async function loadDrinksFromSupabase() {
    const response = await fetch('/api/drinks');
    const drinks = await response.json();
    
    // Получить контейнер меню
    const menuGrid = document.querySelector('.menu-grid');
    if (!menuGrid) return;
    
    // Очистить старые элементы (опционально)
    // menuGrid.innerHTML = '';
    
    // Добавить новые напитки
    drinks.forEach(drink => {
        const item = document.createElement('div');
        item.className = 'menu-item';
        item.innerHTML = `
            <div class="drink-name">${drink.name}</div>
            <div class="drink-price">${drink.price}₽</div>
        `;
        menuGrid.appendChild(item);
    });
}
```

### Пример 2: Создать API маршрут для франшиз

```
app/api/franchises/route.ts

import { supabase } from '@/lib/supabase'
import { NextResponse } from 'next/server'

export async function GET() {
  const { data } = await supabase.from('franchises').select('*')
  return NextResponse.json(data)
}
```

Потом вызвать из JavaScript:
```javascript
fetch('/api/franchises')
  .then(r => r.json())
  .then(franchises => console.log(franchises))
```
